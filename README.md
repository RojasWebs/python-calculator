# React Calculator

A responsive web-based calculator built with React, JavaScript, and CSS.

This project began as a Python calculator and was later rebuilt as a React application as part of my continued development in front-end web technologies.

## Live Demo

[View the live calculator](https://calc.rojaswebs.com)

## Project Evolution

The original version of this project was created in Python, including a desktop GUI version.

I later rebuilt the calculator as a browser-based application using React and JavaScript. This gave me an opportunity to take the logic from an earlier Python project and rethink it for a modern web interface.

The original Python files remain in the repository as part of the project's development history.

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear/reset functionality
- Responsive layout for desktop and mobile devices
- React-based user interface
- RojasWebs branding
